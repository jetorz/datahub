# 福斯特运掌柜市场价采集：运营待确认清单

## 当前试跑基准（仅验证系统）

工具已使用“普货 + 13米 + 高栏”成功查询杭州钱塘区至云南大理市路线，取得市场区间 12,000–15,800 元/趟、参考价 14,190 元/趟。

这证明采集功能可用，但“高栏”及“普货”只是功能验证假设，不能直接作为福斯特正式成本或市场价格基准。

## 请运营同事确认的最小信息

请直接补齐路线 CSV 每一行的货物名称、车长、平台车型和查询重量；不能确认的行不要启动采集。

| 需确认项 | 用途 | 示例或说明 |
| --- | --- | --- |
| 货物名称 | 运掌柜必填，影响可比成交样本 | 普货、光伏胶膜、铝制品等；需采用实际可匹配的平台名称。 |
| 车长 | 运掌柜必填 | 当前本地 `13米_整车` 可暂映射为 `13`；其余长度需给出映射。 |
| 车型 | 运掌柜必填，影响价格 | 平板、高栏、厢式、飞翼等；“整车”不是车型。 |
| 查询重量 | 运掌柜必填，影响价格 | 由运营按货品、车长和车型填写典型查询重量，单位为吨。 |
| 适用范围 | 避免把同一假设套用到不相同业务 | 每一行路线的货物和车型条件必须与实际业务对应。 |

## 建议同时补充的信息

这些字段不是当前页面最低必填项，但决定“市场价”能否与福斯特实际成本公平对比：

| 补充项 | 原因 |
| --- | --- |
| 实际吨位、体积或装载率 | 同一路线不同载重的市场运价可能明显不同。 |
| 包装方式及防雨、防潮、防震要求 | 可能限制可用车型，并影响承运报价。 |
| 回单、装卸、排队、预约、时效要求 | 运掌柜成交样本中常见这些附加条件。 |
| 是否含税、税率、结算口径 | 必须与本地实际成本统一口径后才能比较。 |
| 是否整车、是否多点装卸 | 本地“整车”可确认运输方式，但仍需核对实际操作。 |

| --- | --- | --- | --- | --- | --- |
| 示例：福斯特常规干线 | 杭州、苏州、嘉兴发运的某类常规货物 | 待确认 | 13 | 待确认 | 是否需雨布、回单等 |

## 后续执行顺序

1. 运营补齐 CSV 每行的货物名称、车长和平台车型。
2. 用一条代表路线做试跑，确认结果非空且参数符合实际。
3. 再批量采集其余路线。
4. 只使用查询字段和实际业务条件一致的结果进行成本对比。
